# LMS Platform

A full-stack Learning Management System built using the MERN stack.

## Features
- Authentication with Clerk
- Course management
- Stripe payment integration
- Course ratings
- Responsive UI
- Admin dashboard
- REST API backend

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Clerk Authentication
- Stripe
- Tailwind CSS

## Deployment
- Frontend: Vercel
- Backend: Railway
